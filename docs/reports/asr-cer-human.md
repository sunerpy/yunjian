# 文言语音识别 CER：真人录音（可选，尚未填充）

> **本文件不是任何结论的门禁。** 机器可执行的裁决在
> [`asr-cer.md`](asr-cer.md) 与 [`asr-cer.json`](asr-cer.json)，那份报告用
> **TTS 合成音加信道增强**测得，不需要任何真人录音即可复现。本文件只是留给
> 将来自愿贡献录音的维护者的位置。

## 为什么这一份是空的

现存的中文朗诵音频语料没有一份的授权链能支持本项目的分发形态：

- **MCGA**（ACL 2026 Findings，119 小时 / 22k 条）是 CC BY-NC-SA-4.0。NC 条款直接
  排除本项目，且它只发布了 test split。判定与理由记在 `corpus/DENYLIST.md`。
- 其余可检索到的朗诵数据集或声明「仅供学术研究」，或根本没有许可文件。

自行组织录音需要每位朗读者的明确授权，那不是一个 agent 能在一个 todo 里完成的事，
把它设成门禁只会让这个 todo 永远做不完。所以方案把真人录音明确划为**可选**。

## 合成测量能证明什么、不能证明什么

`asr-cer.md` 的数字是真人 CER 的**乐观上界**。上界的用途是单向的：

- **能证伪**：上界已经超过阈值，真人只会更差，所以语音评分必须退到
  `completeness_only`。这正是当前的结论。
- **不能证成**：上界达标也不等于真人达标。所以即便将来上界降到阈值以内，
  语音路径上的逐字准确率仍然只是 advisory，不会升为分数。

换言之，真人录音**不可能**让结论变得更宽松，只可能让它变得更严。这也是它可以安全地
留作可选项的原因。

## 想贡献录音的话

需要同时满足：

1. 你本人朗读，或你持有朗读者的明确书面授权；
2. 授权允许按 CC0-1.0 或 CC BY-4.0 分发（与本项目的语料许可门禁一致，
   见 `corpus/sources.toml` 的允许列表）；
3. 朗读内容取自 `crates/yunjian-voice/tests/fixtures/cer-poems.toml` 里的 50 首，
   以便与合成测量逐条对照；
4. 16 kHz 单声道 WAV，普通话，不做降噪与后期。

流程：

```bash
# 参考文本（50 首，含体裁标注）
cat crates/yunjian-voice/tests/fixtures/cer-poems.toml

# 录音放在任意目录，文件名用 fixture 的 id，把 `:` 换成 `_`
#   例：五言絕句_元稹_行宫.wav
```

收到录音后，维护者按 `asr-cer.md`「复现」一节的同一条流水线测一遍，把逐体裁 CER
填进下表，并在 `asr-cer.json` 里补 `human` 段。**合成测量的结论不因此被替换**：
两组数字并列呈现，差值本身就是「合成比真人乐观了多少」的度量。
